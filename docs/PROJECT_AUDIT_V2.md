# Project Audit — Voyager Tracker V2

Audit date: 2026-09-25 · Scope: repository `wahaha232/VoyagerTracker`, branch `main` at `7c3cea4` (start of V2) · Live: https://wahaha232.github.io/VoyagerTracker/

Figures below were measured on the built site (`npm run build`, `scripts/content-audit.mjs`, `scripts/check-site.mjs`), not estimated.

## 1. Project structure

| Path | Role |
| --- | --- |
| `scripts/pages.mjs` | Single list of public pages (title, description, schema type, sitemap hints) |
| `scripts/gen-html.mjs` | Writes one Vite HTML entry per page from `pages.mjs` |
| `scripts/prerender.mjs` | Renders every page to static HTML after the build; JSON-LD; `sitemap.xml` |
| `scripts/fetch-horizons.mjs` | Downloads reference data from NASA/JPL Horizons |
| `scripts/validate-model.ts` | Compares the calculations with JPL; writes the validation summary |
| `scripts/check-site.mjs`, `scripts/content-audit.mjs`, `scripts/test-engine.ts` | QA: metadata/links, word counts/duplicates, engine unit tests |
| `src/lib/ephemeris.ts`, `src/lib/context.ts` | Calculation engine and unit/context helpers |
| `src/data/*.generated.ts`, `src/data/events.ts` | JPL reference data, validation summary, sourced mission events |
| `src/pages/*` | 19 page components (React 19 + TypeScript, Tailwind) |
| `src/components/*` | Tracker, charts, explorers, shared UI |

Stack: Vite 6 MPA, React 19, TypeScript, Tailwind 3, Three.js (lazy-loaded 3D model). Hosting: GitHub Pages (`gh-pages` branch, static). No backend, no analytics, no ads.

## 2. Existing pages (start of V2)

18 indexable pages + 404: Home, Voyager 1, Voyager 2, Compare, Mission, Timeline, Science (`discoveries.html`), Golden Record, Why Voyager Still Matters, Tools, How It Works, FAQ, Sources, About, Updates, Contact, Privacy, Terms.

## 3. Existing components

TrackerSection, TrackerCard, VoyagerCanvas (ecliptic map), Voyager3D, HistoryChart, Milestones, SinceLastVisit, MissionExtras (instrument status, per-page sources), Header/Footer/Layout, RelatedLinks.

## 4. Existing data sources

JPL Horizons (state vectors at 2026-09-01, Sun barycentric offset 2020–2040, monthly heliocentric distance/speed 1977–2034); NASA Science mission pages, NASA Voyager blog (instrument status as of 2026-08-04), NASA "Where are Voyager 1 and 2 now?" page.

## 5. Existing calculations

Live position (Taylor-series propagation of barycentric vectors), Earth position (Astronomical Almanac formula), distances, range rate, light time, milestone solving (bisection), unit conversions, hypothetical travel time. Validated 2024–2031, max error 36,176 km.

## 6. Existing charts

History chart (distance/speed 1977–2035, table fallback), ecliptic map (canvas), 3D model.

## 7. Existing calculators

Light time, unit converter, "where was Voyager on…" (Sun distance only), hypothetical travel time.

## 8. Existing navigation

Header: 11 links + logo; mobile menu with all 18 pages; footer in four groups; breadcrumbs; related-link panels.

## 9. Existing SEO

Unique title/description/canonical/OG per page; prerendered HTML; WebSite/WebPage/Article/FAQPage/AboutPage/ContactPage + BreadcrumbList JSON-LD; sitemap with 18 URLs; robots.txt pointing to it.

## 10. Existing legal pages

Privacy (localStorage items listed; AdSense section written conditionally), Terms, Contact (GitHub issues, no fake e-mail).

## 11. Existing accessibility

One H1 per page, skip link, focus-visible outlines, reduced-motion support, labelled controls, chart table fallback, canvases with `role="img"` and descriptive labels.

## 12. Existing performance

Three.js isolated in a lazy chunk (868 KB, loaded after mount only where the model is shown). Main bundle 218 KB (70 KB gzip).

## 13. Existing mobile behaviour

Tested 320–1920 px at the end of V1. V2 re-test found two issues (see §20).

## 14. Existing duplicate content

`content-audit.mjs` found 41 sentences (8+ words) repeated across pages. Almost all were navigation card descriptions and the independence disclaimer (intentional). **One real duplicate:** the home page repeated four FAQ answers word for word.

## 15. Existing thin content

Words inside `<main>` per page ranged from 275 (Contact) to 2,068 (Timeline). No placeholder, "coming soon", TODO or lorem ipsum text. Contact and Terms are short by nature.

## 16. Existing dynamic content

Live estimates (10 Hz), milestone countdowns, since-last-visit panel, map redraw per minute.

## 17. Existing data freshness mechanism

Reference data regenerated by `npm run data`; FAQ figures computed at build date and labelled with it; footer shows build date.

## 18. Existing update mechanism

Updates page: mission events pulled from the sourced timeline + dated website changes.

## 19. Existing unique-value features

Validated calculation model, 50-year JPL chart, compare page, milestone dates vs NASA's, "why the Earth distance shrinks" explanation.

## 20. Missing-value analysis (what V2 addressed)

| Gap | Evidence | V2 action |
| --- | --- | --- |
| Past dates showed only Sun distance | `OnThisDate` used heliocentric history only | Added monthly JPL position vectors; Earth distance and light time for any date 1977–2034; validated separately |
| No two-date comparison, scale ruler or communication simulation | Not present | Added Compare two dates, Scale explorer, Communication delay explorer |
| "Why the Earth distance changes" was text only | FAQ/guide paragraphs | Interactive Earth-orbit diagram with per-day calculated distances |
| Official vs calculated not labelled at point of use | Only a table on How It Works | `SourceBadge` (Official / Calculated / Hypothetical / Educational) on tracker, tools, compare, science, golden record |
| No spot-check table or methodology changelog | Not present | Generated spot checks, historical-accuracy table, changelog |
| Science lacked "before Voyager" context | Topics only | Before / After framing per world |
| Golden Record contents were static cards | `CardGrid` | Category explorer with verified counts |
| Home repeated FAQ answers | content audit | Replaced with links to FAQ anchors |
| Sources had no "last checked" | Not present | Column with the actual link-check date |
| No engine unit tests | Not present | `npm test`, 50 checks |
| Badge overflow at 320 px; header 6 px slack at 375 px | V2 responsive sweep | Fixed; re-tested all 19 pages × 7 widths |
